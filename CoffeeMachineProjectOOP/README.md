# ☕ Coffee Machine (Python)

This is a console-based Coffee Machine application written in Python.

The program simulates a real coffee machine where users can:
- Choose a drink (espresso, latte, cappuccino)
- Insert coins
- Receive change
- Check machine resources
- Turn the machine off

## 📁 Project Structure

.
├── main.py      # Main application loop
├── machine.py   # Coffee machine logic (OOP)
└── menu.py      # Drink menu and prices

## 🛠️ Concepts Used

- Object-Oriented Programming (OOP)
- Dictionaries
- Functions
- Loops & conditionals
- User input handling
