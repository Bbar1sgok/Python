# 🎯 Number Guessing Game (Python)

A simple console-based number guessing game written in Python.  
The player must guess a randomly generated number between **1 and 100** within a limited number of attempts.

---

## 🚀 Features

- Two difficulty levels:
  - **Easy**: 10 attempts
  - **Hard**: 5 attempts
- Input validation for non-numeric guesses
- Clear feedback:
  - Too high
  - Too low
- Replay option after winning or losing
- Clean and modular function-based design

---

## 🧠 How It Works

1. The program randomly selects a number between 1 and 100.
2. The player chooses a difficulty level.
3. The player makes guesses until:
   - The correct number is guessed ✅
   - Attempts run out ❌
4. After the game ends, the player can choose to play again.

---

## 🛠 Technologies Used

- Python 3
- `random` module
